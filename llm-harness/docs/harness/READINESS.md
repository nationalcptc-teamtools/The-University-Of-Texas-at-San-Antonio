# Readiness: private alpha 0.1.0a5

The AI harness has deterministic policy, scope, budget, audit, disclosure,
transport, evidence, coverage, reporting, and export foundations. It remains a
private alpha. No claim of complete CPTC11 detection or general client-safe
scanner execution is made.

Implemented and synthetic-tested:

- fail-closed action envelopes, manual-only denial, immutable module registry,
  target and workflow budgets, durable stop intent, and crash/uncertain states;
- local UTC audit chains, complete bounded output capture, encrypted raw
  evidence, integrity verification, and reviewed local export;
- OpenAI-compatible, captured-request, browser-test, and MCP boundaries with
  compact model state and recursive disclosure validation;
- deterministic imports and checks across network, web, Linux, Windows/AD, and
  reviewed result records;
- bounded HTTP metadata, one-port Nmap, and offline Nuclei/ZAP profiles;
- immutable design catalogs for two SMB NSE observations and one Metasploit
  HTTP observation, plus an exact 184-byte Nmap SMB2 request, exact 50-byte
  NBSTAT wildcard request, fixed HTTP request, and one sealed compound relay
  receipt with cumulative TCP, UDP, request, and byte accounting;
- CVE/CWE/ATT&CK candidate relationships, check-level coverage, findings,
  retest state, and an external benchmark comparator.

Still blocked or incomplete:

- live acceptance for every claimed target profile;
- authenticated Linux, Windows/AD, web, and database collection adapters;
- complete reviewed CPTC11 expected-issue catalog and benchmark comparison;
- active Nuclei/ZAP, live NSE or Metasploit execution, broad Nmap, arbitrary
  scripts, and novel exploitation;
- client-data browser use and unverified provider-side tool behavior;
- manual-only actions such as Zerologon, spraying, credential dumping, DoS,
  service changes, destructive operations, and unknown-impact tests.

The scanner catalog is preparation evidence only. The NSE entries remain
`synthetic_only`; the Metasploit entry remains `design_only`; the bounded proof
catalog is empty. Existing HTTP counters are logical application-layer receipts,
not complete TLS or wire-byte measurements. Live promotion requires the
parent-owned connected relay, dependency closure, packet-count reconciliation,
independent review, and one approved lab endpoint at a time.

Current synthetic verification passes 757 tests under both the system Python
and the pinned Python 3.11 environment. The reviewed allowlist builds
an identical wheel and normalized source archive twice from a fixed epoch. The
installed-wheel smoke check loads the packaged scanner catalog and verifies its
code-anchored hash. This evidence does not admit live NSE or Metasploit traffic.

The `cptc` CLI is retained only as the trusted operator control plane for the AI
harness. The standalone human toolkit and legacy team tooling are maintained in
a separate local project and are not release inputs.
