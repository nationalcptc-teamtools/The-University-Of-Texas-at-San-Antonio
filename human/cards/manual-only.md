# Manual-only result card

Use this card for Zerologon, password spraying, DoS/crash testing, domain
changes, exploit attempts with uncertain impact, or any procedure whose effect
is not contained by an admitted release profile.

- Scope/exclusion/rate or lockout review:
- Human reviewer and disposition: `observed`, `candidate`, `confirmed`,
  `blocked`, or `not_applicable`

The toolkit does not execute this card, accept it as model approval, or infer a
confirmed vulnerability from a claim. Keep raw output and secrets in the
approved local evidence path.
